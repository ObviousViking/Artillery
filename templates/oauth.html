Run OAuth in container

For sites that support it, this runs gallery-dl oauth:<site> inside the container and streams the output here. gallery-dl will print an authorisation URL — open it in your browser, approve access, then paste any code it asks for below. Tokens are written directly to gallery-dl.conf.

Note: This works best when Artillery is accessed from the same machine as the server. For remote access, use the credential form on the left with tokens obtained via docker exec or a local gallery-dl install.
