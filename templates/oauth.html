There's no client-id configured for this site yet, so this will use gallery-dl's default shared app. That app is used by every gallery-dl install out there, and it commonly hits shared quota limits (DeviantArt's "Free download limit reached" is a good example). It's strongly recommended that you register your own app on the site first, then add client-id and client-secret under extractor.<site> in the Config editor.

Click Start, then open the authorization URL that shows up in the log below and approve access. The provider will try to send your browser back to localhost:6414, which is gallery-dl's callback listener running inside this container, so that redirect is going to fail in your browser. That's expected. The page it lands on will still have the code in its address bar even though it failed to load. Copy that URL (or just the part after the question mark) and paste it into the box below, and Artillery will deliver it to the listener for you.
